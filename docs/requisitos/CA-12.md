# CA-12 — Escenario canónico end-to-end

`escenario-canonico` pasa completo en Playwright con dos contextos de
navegador (`DISPOSITIVO-A`, `DISPOSITIVO-B`). La exportación a JSON y CSV
se verifica contra el conteo de eventos. El indicador de almacenamiento
persistente se muestra en ambos estados (concedido/no concedido).

**Verificación**: `app/e2e/escenario-canonico.spec.ts`, sección 13 de la
especificación completa.

**Componentes**: todo el sistema integrado.
