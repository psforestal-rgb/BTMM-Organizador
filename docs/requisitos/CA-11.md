# CA-11 — Sincronización entre dos dispositivos

Push y pull incrementales con puntos de control; idempotencia
demostrada por reenvío del mismo lote sin cambio de estado; fusión por
campo determinista; conflicto en campo crítico registrado con ambos
valores conservados; bitácora nunca sobrescrita; reanudación correcta
tras un corte a mitad de paginación.

**Verificación**: `server/tests/test_sync_dos_dispositivos.py` y
`server/tests/test_sync_idempotencia.py`, más
`server/tests/test_sync_paginacion_reanudable.py`.

**Componentes**: `server/geo/sync/*`, `app/src/sync/*`.
