# CA-04 — Interrupción y reanudación

Interrumpir guarda un marcador de reanudación en texto libre; el
intervalo emergente entra a la bitácora como trabajo real; al terminar la
aplicación ofrece retomar mostrando el marcador literal; la evidencia del
bloque original no se borra.

**Verificación**: prueba Vitest/Playwright que interrumpe una actividad,
registra el emergente, la termina y comprueba que HOY ofrece retomar con
el texto exacto del marcador, y que el bloque original sigue presente en
la bitácora.

**Componentes**: `app/src/dominio/interrupciones.ts`,
`app/src/ui/hoy/Retomar.tsx`.
