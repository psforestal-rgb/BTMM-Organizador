# CA-02 — Captura de fricción mínima

La captura se completa en ≤3 interacciones y persiste en Dexie en <1500ms
sin red, con sello temporal, `device_id` y estado `capturado`. La
clasificación heurística corre después del guardado y nunca bloquea ni
altera el texto original.

El requisito humano de "<20 segundos" se documenta; el proxy medible es
este (interacciones + latencia de persistencia).

**Verificación**: prueba Vitest que mide el tiempo entre `submit` y
confirmación de escritura en Dexie con red simulada apagada; prueba que
verifica que el texto persistido es idéntico al ingresado incluso cuando
la clasificación heurística falla.

**Componentes**: `app/src/ui/capturar`, `app/src/datos/capturas.ts`.
