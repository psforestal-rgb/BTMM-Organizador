# CA-08 — Espera con revisión obligatoria y sin descarte silencioso

El estado `esperando` exige `fecha_revision` (5 días hábiles por
defecto). Al vencer, el radar lo levanta y el sistema propone una acción
de seguimiento. Ningún elemento sale de ninguna vista sin decisión
registrada como evento.

**Verificación**: prueba Vitest que intenta transicionar a `esperando`
sin fecha y espera el cálculo automático; prueba que intenta "descartar"
un hallazgo de RADAR sin decisión y espera un rechazo (excepción o
retorno de error tipado).

**Componentes**: `app/src/dominio/estados.ts`, `app/src/ui/radar`.
