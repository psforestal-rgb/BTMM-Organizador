# CA-05 — Capacidad de absorción real

La agenda nunca programa más de `capacidad_total − buffer_restante`. El
trabajo emergente ya registrado consume primero el buffer.

**Verificación**: prueba Vitest con un caso donde la última candidata es
rechazada con el código `PROTEGIDO_BUFFER_ABSORCION`, y otro donde
minutos emergentes ya registrados reducen el buffer restante y por tanto
aumentan la capacidad programable.

**Componentes**: `app/src/dominio/planificador.ts` (función
`calcularBufferRestante`).
